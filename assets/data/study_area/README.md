# Angkor Wat and regional baray study domain

The study scope includes **Angkor Wat, West Baray and East Baray**. `config.json` and `boundary.geojson` use the existing regional context scene rectangle `[103.6, 13.2, 104.2, 13.8]` (west, south, east, north; EPSG:4326). This deliberately broad search rectangle is not a surveyed archaeological boundary, catchment, or reservoir outline. Metric operations use EPSG:32648.

The prior Angkor Wat clip `[103.8594, 13.4062, 103.8738, 13.4185]` remains separately recorded as `extraction_bbox_wsen`. Current terrain candidates and illustrative flows cover only this core. Expanding study scope does not expand available detailed terrain or create hydraulic links to the barays. `scripts/build_channel_network.py` honors the explicit extraction footprint.

`water_references.geojson` preserves the existing OSM northern moat and reflecting pond polygons and their original tags (ways 160675481, 39842237 and 39842238). Neither baray has a water polygon in this extract; their absence does not remove them from study scope. These modern references do not establish historical connectivity, dates, levels or bathymetry. Attribution: © OpenStreetMap contributors, ODbL 1.0. Existing source citations and hashes remain in `provenance.json`.

Rebuild with `python3 assets/data/study_area/build_boundary.py`. The builder checks finite closed core coordinates and reference-polygon containment. The detail grid has 85,214 centres in the core, 77,416 valid (90.85%) and 7,798 missing. In the regional rectangle, the available sampled TOPSAR overview has 295,460 grid centres, 106,644 valid (36.09%) and 188,816 masked. The region extends beyond that strip; this fraction excludes outside-strip area and is not a regional/native-survey coverage estimate. Overview sampling is about 80 m; the detail scene is about 5 m sampled spacing with roughly 10.8 m nominal along-track resolution. Grid spacing is not ground accuracy.

Missing heights remain masked. TOPSAR and ordinary dry-ground LiDAR cannot establish submerged invert elevations, cross sections, storage curves or reservoir links. Both barays require explicit geometry, bathymetry, levels, connectivity and external conditions before quantitative simulation. Inflow, downstream stage, rainfall, evaporation and seepage remain unset. The study rectangle must not be interpreted as a sealed hydraulic basin.
